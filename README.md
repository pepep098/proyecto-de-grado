# Moti y Moti en Aventura 🎭

Presentación interactiva del Proyecto de Grado de la **I.E. Escuela Normal Superior de Popayán – 2025**.

## 📋 Descripción

**"Moti y Moti en Aventura"** es una propuesta pedagógica de 8 semanas que potencia el desarrollo integral de la **motricidad fina y gruesa** en niños de Prejardín 3 (3–4 años) del Hogar Infantil Pequeñines de Popayán, a través de estrategias lúdicas, artísticas y psicomotoras mediadas por dos personajes: *Moti Grande* y *Moti Pequeño*.

## 🚀 Cómo visualizar

1. Clona el repositorio:
   ```bash
   git clone https://github.com/TU_USUARIO/TU_REPO.git
   ```
2. Abre `index.html` directamente en tu navegador (doble clic).

> No requiere instalación ni servidor. Funciona con cualquier navegador moderno.
